پروژه «اولین پارو | First Paddle»
وب‌سایت فارسی سه‌صفحه‌ای برای دعوت به آشنایی و تجربه اولیه کانوپولو

فایل‌ها:
- index.html : صفحه دعوتنامه
- explore.html : معرفی ورزش کانوپولو
- try.html : تقویم شمسی و فرم علاقه‌مندی
- style.css : طراحی واکنش‌گرا با رنگ‌های سرمه‌ای، آبی و فیروزه‌ای
- script.js : منوی موبایل، تقویم شمسی و تعامل فرم

روش اجرا:
1. همه فایل‌ها را از حالت فشرده خارج کنید.
2. روی index.html دوبار کلیک کنید تا سایت در مرورگر باز شود.
3. برای انتشار آنلاین می‌توانید کل فایل‌ها را در یک مخزن GitHub قرار دهید و GitHub Pages را فعال کنید.

نکته:
- تقویم از پشتیبانی تقویم فارسی مرورگر (Intl) استفاده می‌کند؛ مرورگرهای جدید پیشنهاد می‌شوند.
- فرم فعلاً نمونه آموزشی است و اطلاعات را به سرور ارسال نمی‌کند.
- تاریخ انتخاب‌شده به معنی رزرو قطعی نیست.
- تصویر قایق در صفحه اول با CSS ساخته شده است؛ برای پروژه بدون نیاز به فایل تصویری خارجی کار می‌کند.
- فونت Vazirmatn در صورت اتصال اینترنت از Google Fonts بارگذاری می‌شود؛ در غیر این صورت فونت جایگزین نمایش داده می‌شود.
